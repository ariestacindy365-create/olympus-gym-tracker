# Olympus Musik (extension Chrome)

Mengecilkan musik **YouTube di tab lain** ke 20% saat slideshow coach
mengumumkan PR, lalu membesarkannya lagi pelan-pelan setelah selesai.

## Pasang (sekali saja di laptop/TV kelas)

1. Unduh `olympus-musik.zip` (di slideshow: 🎵 Musik → "Pasang extension"),
   lalu ekstrak.
2. Buka `chrome://extensions`, nyalakan **Mode developer** (kanan atas).
3. Klik **Load unpacked** → pilih folder `olympus-musik` hasil ekstrak.

Buka YouTube di tab lain seperti biasa (tab yang sudah terbuka sebelum pemasangan juga ikut), lalu buka Slideshow Olympus dengan
🔊 PR menyala. Tanpa extension, pengumuman tetap jalan; musiknya saja yang
tidak mengecil.

## Perbarui

Kalau dipasang dari folder proyek: `git pull`, lalu di `chrome://extensions`
klik ↻ pada Olympus Musik. Kalau dari zip: unduh zip baru, ekstrak menimpa
folder lama, lalu klik ↻.
